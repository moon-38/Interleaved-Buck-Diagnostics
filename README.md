# Interleaved Buck Probing: Supporting Study

Supporting software and data for **Output Cost of Two-Tone Probing in a Two-Phase Buck Converter: A Simulation Study**.

Authors: Jeong-Hoon Moon and Sang-Kil Lim (equal first contribution), and Jung-Hwan Lee (corresponding author).

The current study compares required two-tone probes across current budgets, starting ratios and acceptance guards. Tone RMS, observation-error distributions, acquisition excursions and running excursions are distinct outcomes.

This repository is being populated with verified source and data. No DOI or licensed archival release has yet been assigned. IEEE template assets and author photographs are excluded from the public code/data bundle.
